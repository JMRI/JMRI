Introduction

 

JMRI PanelPro Layout Editor is a sophisticated schematic panel editor designed specifically for model railroad operators who need to draw accurate track diagrams while simultaneously capturing full layout connectivity. Unlike the simpler icon-based Panel Editor — where the operator manually places pre-drawn images of turnouts, sensors, and signals without any underlying logic — the Layout Editor uses drawn track components (turnouts, track segments, anchor points, end bumpers, level crossings, turntables, and more) that carry embedded connectivity and block/signal logic. As the operator draws the track diagram, Layout Editor automatically understands which track segments are connected, which blocks they belong to, and where signal heads and masts must be placed to protect those blocks. This makes Layout Editor the preferred choice for operators building complete Automatic Block Signaling (ABS) or ERTMS-style signaling systems from the panel itself, without manually editing XML files or writing scripted logic.

This reference document is organized for practical use at the workbench. The key operational distinction is between Edit Mode and Non-Edit Mode (also called operating mode). Nearly all item placement, repositioning, and right-click popup menu operations require Edit Mode to be active — toggled via Options > Edit Mode. When Edit Mode is off, the panel behaves as an operator panel: left-clicking toggles turnouts and sensors, but items cannot be moved or placed. A second important cross-platform distinction concerns the Meta key: on macOS, this is the Command (⌘ / Cmd) key; on Windows and Linux, the Meta function is implemented as holding the right mouse button while dragging. The JMRI help bar (Options > Show Help Bar in Edit Mode) identifies the platform-specific key names in real time at the bottom of the panel window.

The scope of this document is comprehensive. The main body (Sections 1–11) covers the Layout Editor in full detail: item placement, repositioning, track segment drawing, context menus, zoom, pan, turnout control, markers, coordinate display, icon operations, and shape drawing. Appendix A covers the Control Panel Editor, which adds Warrant-based automatic train running. Appendix B covers the traditional Panel Editor, which is entirely icon-based. Appendix C provides a unified modifier key cross-platform reference table, and Appendix D covers the Help Bar and practical usage tips. All version-specific features are noted with their minimum JMRI version in parentheses. This document is based on JMRI version 5.x documentation and is intended for model railroad hobbyists at all experience levels who use JMRI PanelPro on Windows, macOS, or Linux.

Section 1 – Item Placement (Edit Mode)

 

1.1 Entering Edit Mode

Edit Mode is the primary configuration state of the Layout Editor. All item placement, repositioning, and context menu operations require Edit Mode to be active.

●      Enable/Disable: Options menu > Edit Mode (check to enable; uncheck to disable)

●      Visual indicators when Edit Mode is ON: The toolbar is visible; red, green, magenta, and blue connection point squares appear at track endpoints and connection locations; circular edit handles appear at item centers (turnouts, level crossings, turntables)

●      Help bar: Displayed at the bottom of the panel window when Edit Mode is active. Enable or disable via Options > Show Help Bar in Edit Mode. The help bar provides context-sensitive hints including platform-specific key names.

 

Note

When Edit Mode is turned off, the toolbar is hidden, all connection squares and edit circles are hidden, popup menus are not active, and items cannot be repositioned. The panel behaves as a pure operator display.

1.4 Shape Drawing Detail

●      First point: Shift + Left-Click places the first vertex of the shape

●      Additional points: Drag a line from any existing vertex point; the new vertex is created at the position where the mouse is released

●      Right-click on a vertex or shape center: Opens the shape attribute menu (line color, fill color, open vs. closed type)

●      Open → Closed: Selecting "Closed" draws a final line connecting the last point back to the first point, creating a closed polygon

●      Rectangle: Draw three line segments (producing four vertices), then select Closed — the fourth side is drawn automatically

●      Drag mechanics: The drag process is identical to drawing a Track Segment, except there is no destination connection point required — the new vertex is created wherever the mouse is released

1.5 Toolbar Combo Box Color Coding

When entering names into toolbar combo boxes (turnout name, block name, sensor name, etc.), the background color of the field indicates the validity of the entered name:

 

Background Color

Meaning

Green

Name matches an existing item in the corresponding JMRI table (turnout table, sensor table, etc.)

Yellow

Name does not yet exist — a new item will be created with this name when placed

Red

Name is invalid or cannot be used (duplicate, illegal characters, etc.)

 

1.6 Snap to Grid Behavior

●      Snap when Adding: Options > Grid Options > Snap to Grid when Adding — constrains new item placement coordinates to the nearest grid intersection

●      Snap when Moving: Options > Grid Options > Snap to Grid when Moving — constrains repositioned item coordinates to the nearest grid intersection

●      Track items: The center point coordinates are snapped to grid

●      Icons and labels: The upper-left corner coordinates are snapped to grid

●      Grid Size: Options > Grid Options > Grid Size… — configurable; default is 10 pixels

Section 2 – Moving & Repositioning Items

 

2.1 Prerequisite

To move most items, two conditions must be met simultaneously:

1.     Edit Mode must be active (Options > Edit Mode)

2.     Options > Allow Repositioning must be checked

 

Exception — Markers

Markers are the only panel items that can be repositioned in any mode, at any time

, regardless of whether Edit Mode or Allow Repositioning is enabled. This is intentional, allowing train position markers to be updated during operations without entering Edit Mode.

2.4 Grid Snapping During Move

When Options > Grid Options > Snap to Grid when Moving is checked, items snap to the nearest grid intersection as they are dragged. The grid size is configurable via Options > Grid Options > Grid Size… (default: 10 pixels). Snapping applies to the same coordinate point as placement: the center of track items, and the upper-left corner of icon-based items.

Section 3 – Track Segment Operations

 

3.1 Drawing a Track Segment

Track segments are the connecting lines drawn between track items. They are drawn using a click-and-drag gesture originating at a connection point.

3.     Select the Track Segment radio button in the toolbar

4.     Optionally check Dashed and/or Mainline in the toolbar

5.     Optionally enter a Block Name and/or Occupancy Sensor in the toolbar combo boxes

6.     Hold the Shift key

7.     Press and hold the mouse button on one red (empty) connection point

8.     Drag toward the destination red connection point — the cursor shape will change when hovering over a valid target

9.     Release the mouse button at the destination point, then release Shift

 

Note

The track segment can only be connected to

empty

(red or magenta) connection points. Green and blue squares indicate that the connection point is already at its maximum number of connections and cannot accept another segment.

7.3 Turnout Circle Visibility

By default, turnout edit circles are only visible during Edit Mode. To display turnout circles when not in Edit Mode (making it easier to click-to-toggle without visual guides), enable Options > Turnout Options > Show Turnout Circles.

The size of these circles — and thus the clickable "hot spot" area — is configurable via Options > Turnout Options > Turnout Circle Size. Reducing the circle size is useful in crowded track areas where it may be difficult to click one specific turnout without accidentally triggering an adjacent one.

7.4 Turnout Animation

Options > Turnout Options > Allow Turnout Animation: when checked, the turnout graphic animates (moves visually) when the turnout changes state, providing clearer visual feedback during operations. Uncheck to disable animation for faster response.

Section 9 – Coordinate Display & Navigation

 

9.1 Coordinate Display

●      Location: Upper-right area of the toolbar (visible in Edit Mode)

●      Shows: x (horizontal) and y (vertical) pixel coordinates of the current cursor position on the panel

●      Purpose: Enables precise alignment of items during layout construction — move the cursor to check exact coordinates before clicking to place an item

●      Updates: Real time as the cursor moves over the panel

●      Floating Toolbox: When using the floating toolbox (Options > ToolBar > Float), both cursor coordinates and current zoom factor are displayed in the floating window

9.2 Save Location and Size

●      Access via: Options > Save Location and Size

●      Visibility condition: This menu item is only displayed when "Use old location and size logic for editor panels" is enabled in Preferences > Display

●      Function: Records the current panel window position and size; these values are restored the next time the panel is loaded from file

●      Important: The panel window position and size only update in the saved file when this item is explicitly selected. Simply moving or resizing the window does not automatically save those changes.

Appendix A – Control Panel Editor Shortcuts

 

A.1 Overview

The Control Panel Editor (CPE) is an intermediate-level panel editor that provides menus instead of a separate editing window (as used by Panel Editor). CPE supports Warrants and automatic train running — allowing the operator to define automatic routes and have JMRI drive trains along them. CPE uses the same Meta+Drag and right-click mechanisms as Layout Editor and Panel Editor for icon manipulation, making the interaction model consistent across all three editors.

A.3 Indicator Track Icons (CPE-Specific)

Control Panel Editor supports Indicator Track icons — specialized track icon images that automatically change color based on block occupancy state. This provides a visual equivalent to Layout Editor's block coloring feature but implemented entirely through icon images rather than drawn track. Indicator Track icons respond to the same sensor-based block detection system and can be configured to show occupied, unoccupied, and train-location states using different icon images for each state.

Appendix B – Panel Editor Shortcuts

 

B.1 Overview

Panel Editor is the traditional icon-based panel editor in JMRI and the predecessor to both Layout Editor and Control Panel Editor. In Panel Editor, all panel elements are represented by icon images — there is no drawn track connectivity, no block logic, and no automatic signal management. Icons are placed by selecting the item type from a dropdown list in the separate Panel Editor window, configuring the item, and clicking Add to Panel. All manipulation once placed uses the Meta key for dragging and right-click for context menus, consistent with the other editors.

Appendix D – Help Bar Reference & Tips

 

D.1 Help Bar

●      Location: Bottom of the Layout Editor panel window

●      Enable/Disable: Options > Show Help Bar in Edit Mode

●      Content: Displays context-sensitive hints for current UI interactions, including platform-specific key names based on the detected operating system

●      Recommendation: Keep the help bar enabled while learning JMRI Layout Editor. Once operations become familiar, the help bar can be disabled via the Options menu to gain additional screen space.

D.2 Toolbar Coordinate Display

●      Location: Upper-right of the toolbar (Edit Mode only)

●      Shows: Real-time cursor x and y coordinates in panel pixels

●      Use: Precisely align items during drawing. Position the cursor at the exact location, read the coordinates, then Shift+Click to place with precision.

D.3 Floating Toolbox

●      Access via: Options > ToolBar > ToolBar Side > Float

●      Description: A floating, resizable toolbox window that can be positioned anywhere on the screen — useful on multi-monitor setups

●      Organization: Organized on 4 tabs: Turnouts, Track, Labels, and Icons

●      Displays: Current zoom factor and cursor location coordinates

●      Close button: Hides (does not delete) the toolbox; restore via the Window menu

●      Minimize button: Sends the floating toolbox to the OS taskbar

D.4 Edit Mode Toggle — Visual Indicators

 

State

Visual Indicators

Toolbar hidden; all connection squares hidden; edit circles hidden; popup/context menus not active; items cannot be repositioned (markers excepted)

 

D.5 Practical Tips

Alignment Precision

Use the x,y coordinate display (upper-right of toolbar) to align items. The display updates in real time as the cursor moves. Position the cursor at the desired location, read the coordinates, then click to place with maximum precision.

Turnout Orientation for Signal Logic

Layout Editor's signal configuration tools (Set Signals at Turnout, Set Signals at Block Boundary) work most reliably when turnouts are oriented approximately vertically or horizontally on the panel. While exact alignment is not mandatory, turnouts that are significantly diagonal may cause the automatic signal logic tools to produce unexpected results.

Save Panel Frequently

Use Options > Save Location and Size to save the panel window position, then use File > Store All to File… to save panel content frequently during editing. Remember that the panel window position only updates when "Save Location and Size" is explicitly selected — it does not save automatically when the window is moved.

Snap to Grid for Clean Layouts

Enable both Snap to Grid when Adding and Snap to Grid when Moving (Options > Grid Options) during initial layout construction for clean, aligned track plans. The default grid size of 10 pixels provides a good balance between precision and flexibility. For very complex layouts with diagonal elements, temporarily disable snap during placement of diagonal track sections.

Turnout Circle Size and Hot Spot

Options > Turnout Options > Turnout Circle Size controls both the visual size of the turnout circle marker and the effective clickable "hot spot" area that responds to mouse actions. In crowded areas with closely spaced turnouts, reducing the circle size makes it easier to click one turnout without accidentally activating an adjacent one.

Block Boundary Signal Configuration

The Set Signals at Turnout and Set Signals at Block Boundary tools (Tools menu) require turnouts and anchor points to be oriented approximately vertically or horizontally for automatic signal head and mast assignment and logic configuration to succeed. Review panel orientation before running these tools.

Highlight Cursor Position (since JMRI 5.11.3)

Options > Highlight Cursor Position draws a colored highlight box around the mouse pointer position when clicked — particularly useful on touch screens or high-resolution displays where the cursor may be difficult to locate. This feature is not active in Edit Mode. Additionally, turnout circles flash briefly during state changes to provide visual confirmation of the toggle action.

Track Labels Debug Toggle

Options > Toggle Track Labels in Edit Mode displays internal JMRI system names for all track elements (anchor points, track segments, turnouts, level crossings, etc.) directly on the panel surface. This is a diagnostic and verification tool — useful for confirming that block assignments, sensor connections, and signal logic are configured to the correct track elements, particularly when troubleshooting complex panel layouts.
