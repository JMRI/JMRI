Lenz XPressNet

  • Fixed an issue where a throttle could stop sending speed and function commands for its locomotive after receiving an unrecognized locomotive information response, requiring a JMRI restart to recover.

LocoNet

  • SlotMonitor update:
    • Add ability to hide / move columns. N.B. if you open 2 or more SlotMonitors this is only effective on the first one.
    • If Extended purge time is enabled in the Command Station the Slow scan for slots is extended.
    • If purging is disabled in the Command Station so is slow scanning.
      • A value of -1 stops slowscanning.
  • Remove some extra messages when configuring with the board-level tools in the LocoNet menu
  • Added a new programming facade "Digitrax OpSw Word Programming" for programming at the board level for e.g. DS64's.
  • You can now program, save and load DS64 output addresses and routes in a roster entry using DecoderPro.
  • Add in-use count to the Slot Monitor.
  • Timeouts when programming the Op Switches on Digitrax boards (e.g. DS64, etc) will automatically be retried once.
  • Added interpretation of some BDL716 configuration messages to LocoNet Monitor.
  • Made some LocoNet-specific programming mode constants public so the can be accessed from scripts.
  • LocoNet Clock now uses the same throttle ID as the rest of JMRI, instead of (illegal) 00 00.
