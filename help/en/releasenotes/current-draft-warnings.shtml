• Dispatcher: with "Place train name in allocated Blocks" on, the value of an allocated Block no longer holds the train it is allocated to. A Logix, LogixNG or script that reads the value of an allocated Block now gets only the train Block tracking has placed there: nothing where the Block is empty, or where Block tracking could not tell which train entered. To get what the value gave before, use getDisplayValue(); for only the train the Block is allocated to, getAllocatedValue(). Dispatcher logs a note the first time this applies in a session. With the option off, nothing changes. See the Dispatcher section of the release notes.
  • The fast clock implementation has been reworked and therefore tables and panel files stored with this JMRI release will not load with earlier JMRI releases.
