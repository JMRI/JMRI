Roster Speed Profiling

The Speed Profiling tool is designed to create a profile of a loco at various speed steps to help with the automatic running of a loco within JMRI using either DispatcherPro or Warrants. The primary goal is getting a loco to stop, or change speed (Ramping) within a specific distance using known Throttle settings.

The tool is accessed through PanelPro's Roster ⇒ Speed Profiling menu item or DecoderPro's Actions ⇒ Speed Profiling menu item.

It works on the principle of timing a loco over a known distance at a given speed step, in both the forward and reverse directions. It requires three sensors which monitor the occupancy around three contiguous sections of track. Ideally the middle section of track that the timed runs are performed over should be straight, and a minimum of 1 meter long; the longer the length the better the result. For this profiling to work correctly, acceleration/deceleration should be disabled in the loco decoder.

Settings

  • Block Length - This is the length of the middle section where the timed run will be measured. The value is either millimeters (mm) or inches (in) depending on the selected unit of measure. Note: Changing the unit of measure does not change the value. A new length value will need to be entered.
  • Sensor Delay Adjust (milli secs) - The elapsed time can be reduced to compensate for sensor delays.
  • Create Sensors if Not Defined - Normally a PanelPro layout data xml file is loaded which includes the three occupancy sensors. If the three sensors have been defined with only system names and the preferences have been saved using Save Preferences, the sensors can be automatically created when the Speed Profiling tool is started.
  • Start Sensor - This is the occupancy sensor for the initial section of track that the loco will start its initial run from.
  • Block Sensor - This is the occupancy sensor for the timed section of track. The timing starts when this sensor becomes active.
  • Finish Sensor - This is the occupancy sensor for the section of track immediately after the timed section. The timing stops when this sensor becomes active.
  • Roster Entry - Select the loco to be profiled. When the entry is selected a temporary throttle is used to determine speed step mode being used.
  • Throttle Type - Displays the DCC address and speed steps that will be used by the profiling process.
  • Start - Starts the profiling process.
  • Test - Test the existing Speed Profile (see below).
  • Cancel - Cancels a profiling or test run.
  • View New - Opens a table of the speed profile captured in the current session.
  • View Merged - Opens a table of the speed profile captured in the current session merged with the current profile.
  • View Current - Opens a table of the speed profile currently saved in the roster entry.
  • Profile Start Step - The first speed step to profile.
  • Profile End Step - The last speed step to profile.
  • Increment/Decrement Steps by - The amount is added or subtracted to get the next step. The label Increment/Decrement will automatically change depending on whether the start step is greater or less than the finish step.
  • The speed step values must be greater than zero and must not exceed the Maximum number of speed steps for the throttle. If values are not entered they start at 1 and finish at Max Speed Steps, incrementing by 1.

Profiling

To profile the loco, fill the above details into the pane, place the loco in the starting section facing forwards towards (but not on) the track Block that the timed run will be taken over, then press Start.

What happens is that the tool will set the loco off running in the forward direction at the Profile Start Step. When it activates the timed section sensor it starts a timer. Once the finish section sensor is activated the timer is stopped, and the speed is calculated in Millimeters per Second. This is then recorded in the New profile table. The tool will then ensure that the loco is clear of the timed section sensor, then repeat the procedure again but in the reverse direction. Once the loco is back at the initial start section, the whole procedure is repeated again for the next speed step, this occurs until the Profile End Step has been completed.

Profiles can be made with fewer speed steps by choosing the steps to start and end on, and how many steps to increment/decrement to the next sampling step. When a starting step is larger than 4 be sure to place the loco in a position that will allow it to achieve full speed before reaching the block sensor.

The first four buttons at the bottom are used to manage the speed profile within a roster entry.

Clear New Data
Discard the most recent results.
Save Merged
Combines and saves whatever profiling has been done with the existing speed profile in the Roster entry.
Save New
Add a new speed profile or replace an existing speed profile in the Roster entry.
Delete Current Profile
Remove any Speed Profile from the Roster entry.
Save Preferences
Store the basic settings and sensor names to the configuration file. These will be used when starting a new Speed Profile session.
Profiling Status

While the profiling process is running, a series of messages is displayed in the lower left portion of the window. This is the initial message while waiting for the middle sensor to become active.

Once the middle sensor becomes active, the message changes to show the current step and direction: Profiling Step (Forward) 1 of 121.

When the destination sensor becomes active, the timing is done, but loco has to clear the middle section before it can be stopped: Waiting for Loco to clear Block Sensor....

Testing

Having completed the profiling, it is possible to test a Profile. Place the loco in the starting Block again, facing forward toward the timed Block, ideally some distance away from it. Enter a starting speed number in the Test Data - Step box, then press Test.

What will occur is that the tool will set the loco running at the given speed step over the Test Block, stop and reverse at the same Step. Measured speed will be reported in the Forward and Reverse boxes.

Results will vary especially at the higher speed steps, where you will more likely experience an over run.

Viewing

Click one of the buttons in the View area to open a table showing the profile values for either the New Profiling results, Current stored in the Roster or a combination of both. Cells in the table contain the speeds attained by the loco for each throttle step in both directions.

The default speeds are in millimeters per second as measured layout track speed. These values can be converted to scale speeds by selecting either of the "Miles/hr" or "Kilometers/hr" (per Hour) radio buttons over the table.

The Factor column is the ratio of track speed (mm/sec) to throttle setting (from 0.0 to 1.0).

In the example (using simulated timings) cells with unexpected (non-incrementing) values are marked in red. Such cells are editable to correct the value or the whole row for that step can be deleted. Normally the red instruction will not display.

The default Units selection is set using Preferences ⇒ Warrants.

This setting is also used by the Test results. If Miles/hr or Kilometers/hr are selected the layout scale also needs to be selected in Warrants preferences.
